The Homelab

A single Linux server running headless (no desktop session, to save memory), reachable only through a private VPN mesh — nothing is exposed to the internet by raw IP. Traffic flows: Tailscale mesh → firewall (UFW, default-deny) → DNS resolution (Pi-hole) → reverse proxy + TLS termination (Nginx Proxy Manager) → individual service, with Authentik sitting in front of anything that needs single sign-on and MFA.

DieNamic Engine Core

A Kivy/Python game engine I designed and built from scratch, targeting desktop (Windows/Linux/SteamOS) and Android. It hosts six playable horror-parody titles (detailed on the games page) on one shared core — new games are added by writing game-specific data and mixins, never by editing engine internals.
