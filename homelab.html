The Homelab

A single Linux server running headless; no desktop session unless I want. The choice was intentional, to save memory since the tower is from ~2010.
The lab is reachable only through a private VPN mesh accessible from my phone, laptop and tablet — nothing is exposed to the internet by raw IP.

Traffic flows: Tailscale mesh -> firewall (UFW, default-deny) -> DNS resolution (Pi-hole) -> reverse proxy + TLS termination (Nginx Proxy Manager) -> individual service, with Authentik sitting in front of anything that needs single sign-on and MFA.

The 'DieNamic Engine'

A Kivy/Python game engine core I designed and built from scratch in my spare time, targeting desktop (Windows/Linux/SteamOS), Android and eventually iOS.
It hosts six playable horror-parody titles (detailed on the games page) on one shared core, like a regular console — new games are added by writing game-specific data and mixins that extend the core functionality to meet each game's needs, never by editing engine internals. This allows for rapid prototyping and iteration, and for the engine to be used as a base for future projects.
The core engine was pieced together after coming across a Reddit post about there not being a 'Final Destination' game. Knowing I couldn't create and manipulate 3D environments yet, but knowing damn well that I could write stories in that universe, the decision was made to create one and to start simple. I settled on a branching text adventure like those old 'Goosebumps' books I grew up on. A single shell script about a deadly house ("House Trap") was the starting point.


As an amateur game developer, I had to start asking myself down to earth questions. What do all games need? A world to take place in. A location became a navigable map, that map got filled with objects, those objects got descriptions, attributes and details, those details became lore, that lore became unlockable through action. Find the item, unlock the backstory in a journal. Along came achievements, character types with their own strengths and weaknesses, an antagonist that learns from your actions, chain-reactive dangers.. The idea was converting movie tropes into game mechanics, and I have a blast doing it. There are games that emulate John Carpenter's The Thing, Saw, A Nightmare on Elm Street, and whatever else I can think up, all with their own separate functions that all work on the same core engine.
